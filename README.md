# Freedom of Speech — проверка текста на соответствие законам РФ

Десктопное приложение на PyQt6: пользователь вставляет текст, а программа проверяет его по **локальной базе статей УК/КоАП РФ** и по **паттернам чувствительных персональных данных**. Всё работает офлайн — текст никуда не отправляется.

**Версия:** 1.0.0  
**Статус:** Pet проект  
**Стек:** Python, PyQt6, Regex (стандартная библиотека `re`)

## Возможности

- Локальная база нарушений: экстремизм, терроризм, клевета, оскорбление, фишинг, мошенничество и другие
- Для каждого нарушения выводится категория, статья, наказание и уровень серьёзности с цветовой индикацией
- Детектор чувствительных данных: паспорт РФ, ИНН, СНИЛС, номер карты, телефон, email, домашний адрес, пароли
- Маскирование найденных значений в интерфейсе (`45***56`), чтобы сам инструмент не создавал новую утечку
- Учёт русских словоформ в паттернах (`\w*` по корню слова), а не только словарных форм
- Два режима проверки: логика работает даже без установки PyQt6 (`test_examples.py`)

## Быстрый запуск

Нужен Python 3.10 или новее. Склонируйте репозиторий, создайте виртуальное окружение и установите зависимости:

```bash
git clone https://github.com/<USER>/FreedomOfSpeech.git
cd FreedomOfSpeech
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python russian_law_checker.py
```

Linux / macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python russian_law_checker.py
```

Откроется окно приложения. Вставьте текст в поле ввода и нажмите **🔍 Проверить текст** — результаты появятся на двух вкладках.

## Использование

1. Вставьте текст в поле «Введите текст для проверки»
2. Нажмите **🔍 Проверить текст**
3. Переключайтесь между вкладками:
   - **📋 Нарушения законов** — таблица: нарушение, статья, наказание, серьёзность
   - **⚠️ Чувствительные данные** — таблица: тип данных, маскированное значение, позиция в тексте, уровень риска
4. **🗑️ Очистить** сбрасывает поле ввода и обе таблицы

| Элемент | Действие |
| --- | --- |
| `🔍 Проверить текст` | Запустить проверку по обеим базам |
| `🗑️ Очистить` | Сбросить ввод и результаты |
| Вкладка «Нарушения» | Найденные статьи с цветовой индикацией серьёзности |
| Вкладка «Чувствительные данные» | Найденные ПДн с маскированием значений |

## Как это работает

### Что такое Violation?

**Violation** — dataclass, описывающий одну статью базы:

```python
@dataclass
class Violation:
    category: str      # "Экстремизм"
    description: str   # человеческое описание нарушения
    article: str       # "УК РФ ст. 282"
    punishment: str    # "Штраф до 300 000 руб. или лишение свободы до 4 лет"
    severity: str      # critical | high | medium | low
```

### Что такое SensitiveData?

**SensitiveData** — находка детектора ПДн:

```python
@dataclass
class SensitiveData:
    data_type: str            # "Паспорт РФ", "Email адрес", ...
    value: str                # исходное значение (в GUI маскируется)
    position: Tuple[int, int] # span в тексте (начало, конец)
    risk_level: str           # critical | high | medium
```

### Как работают детекторы?

Оба детектора — это списки **регулярных выражений**, которые прогоняются через `re.search` / `re.finditer`:

```python
# Нарушения: корень слова + \w* покрывает словоформы
r'(бей\w*|убива\w*|расстрелива\w*|веша\w*)\s+(русск\w*|евре\w*|татар\w*|кавказц\w*)'

# ПДн: структурные паттерны
r'\b\d{4}\s+\d{6}\b'                                  # паспорт
r'(?:\+7|8)[-\s]?\d{3}[-\s]?\d{3}[-\s]?\d{2}[-\s]?\d{2}'  # телефон
```

**Почему корни слов, а не словарные формы?** Паттерн `убить` не поймает «убей», «убейте», «убивал». Корень `уби\w*` покрывает всё семейство словоформ — это заметно повышает полноту regex-подхода.

**Почему значение маскируется в таблице?** Если инструмент показывает найденный пароль или номер карты в открытом виде, скриншот интерфейса сам становится утечкой. Поэтому выводится `45***56`.

### Архитектура приложения

```
LawCheckerApp (QMainWindow)
        |
    QTextEdit           ← ввод текста
    QPushButton ×2      ← "Проверить", "Очистить"
    QTabWidget
        |
    ├─ QTableWidget     ← Нарушения (Violation)
    └─ QTableWidget     ← Чувствительные данные (SensitiveData)
    QLabel              ← строка статуса
```

Проверка синхронная: `check_text()` → `db.check_violations(text)` и `db.detect_sensitive_data(text)` → заполнение таблиц. Цвет ячейки «Серьёзность»/«Риск» задаётся через `setBackground(QColor(...))` — красный/оранжевый/жёлтый/зелёный.

## Ограничения — важно понимать

Это **демонстрационный** инструмент на основе ключевых слов и regex, а не юридический или NLP-анализ:

1. **Ложные срабатывания неизбежны.** Паттерн «угрозы + этнос» может сработать на сарказм, цитирование или новостной пересказ без реального умысла.
2. **Пропуски тоже возможны.** Любая перефразировка, опечатка или синоним, не заложенный в паттерны, останется незамеченной.
3. **Это не юридическая консультация.** Квалификация деяния по статье требует контекста, умысла и состава преступления — этого не определить регулярным выражением. Инструмент годится как первичный фильтр/подсказка, не как основание для решений.
4. **Числовые паттерны ИНН/СНИЛС/паспорта** — это просто 10–12 цифр, они могут срабатывать на случайные числа в тексте.
5. Для продакшен-уровня точности нужен NLP-классификатор на нейросети и юридически выверенная база, а не список regex.

## Приватность

- Приложение **не отправляет данные никуда** — вся обработка локальна, в памяти процесса
- Найденные данные в интерфейсе маскируются
- Если планируете логировать проверки для аудита — храните только маскированные значения и хэши, не сырые данные

## Решение проблем

### ImportError: No module named 'PyQt6'

```bash
pip install PyQt6
```

Linux (альтернатива через системный пакет):

```bash
sudo apt-get install python3-pyqt6
```

### Окно не открывается

Убедись, что:
- Ты работаешь на машине с дисплеем (не в SSH без X11)
- Используется Python 3.10+

### Нужны тесты без GUI

```bash
python test_examples.py
```

Тесты используют копию логики проверки без импорта PyQt6 — подойдут для CI или машины без графического окружения.
